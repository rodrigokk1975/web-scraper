# Web Scraper com Relatório CSV

Projeto em Python para demonstração de **coleta, limpeza, organização de dados e geração de relatórios em CSV** usando `requests` e `BeautifulSoup`, direcionado ao sandbox educacional [`books.toscrape.com`](https://books.toscrape.com/).

## Boas Práticas e Ética

- Sempre respeite o `robots.txt` e os Termos de Uso do site alvo.
- Identifique suas requisições com um `User-Agent` claro e aplique intervalos entre requisições (*rate limiting*).
- Em cenários reais, **prefira sempre uma API oficial** quando disponível.
